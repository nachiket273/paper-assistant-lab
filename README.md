# paper-assistant-lab
A lightweight system that ingests scientific papers, retrieves relevant sections, answers technical questions with citations, and evaluates retrieval/generation quality.

## Problem
Scientific papers are difficult to search, and LLMs hallucinate.

## Goal
Build citation-aware question answering over scientific papers.

## Roadmap
* PDF ingestion
* chunking
* embeddings
* retrieval
* answer generation
* evaluation
